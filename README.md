# Inam Ali Online Platforms

Urdu-first Android learning app for online platforms and digital skills.

## Build
GitHub Actions builds a debug APK on every push to main and on manual dispatch.
Open Actions → Build Android APK → latest successful run → Artifacts → Inam-Ali-Online-Platforms-APK.

## Notes
- App content is starter curriculum structure, not a complete verified course library yet.
- Platform eligibility, age requirements, monetization and payout rules change; verify official sources before relying on them.
- No earnings are guaranteed.
